# EE-Portfolio

This repository is a curated electrical engineering portfolio featuring projects that demonstrate skills in analysis, simulation, embedded systems, and software development.

Each project emphasizes practical system design, implementation, and validation.

## Featured Projects

### Automated Battery Cell Inspection & Sorting System
Developed an automated inspection and sorting system integrating PLC control logic, HMI visualization, electrical schematics, and Python-based production analytics. Implemented cell inspection, reject sequencing, fault handling, production counters, and system monitoring.

**Tools & Technologies:** CODESYS, Ladder Logic, HMI, AutoCAD Electrical, Python

---

### Autonomous Maze Navigation Robot (EEBOT)
Programmed an autonomous mobile robot using HCS12 assembly language. Integrated sensor inputs, ADC measurements, DC motor control, and LCD output to implement autonomous navigation and system control.

**Tools & Technologies:** HCS12 Assembly, Embedded Systems, ADCs, Sensors, DC Motors

---

### 8-bit CPU Design
Designed and simulated an 8-bit CPU composed of an arithmetic logic unit, registers, control logic, and supporting digital components. Implemented and verified combinational and sequential logic modules.

**Tools & Technologies:** VHDL, Digital Logic, FPGA Design Concepts

---

### Signal Analysis Using MATLAB
Applied MATLAB to analyze signals in the time and frequency domains using signal-processing techniques including Fourier Series and Fourier Transform analysis.

**Tools & Technologies:** MATLAB, Signal Analysis, Fourier Series, Fourier Transform

---

### Linear Voltage-Controlled Multi-Function Waveform Generator
Designed, simulated, and implemented an op-amp-based function generator producing square and triangular waveforms with linear voltage-to-frequency control. Developed two selectable frequency ranges and adjustable output amplitude, then validated the design by comparing theoretical calculations, Multisim simulations, and hardware measurements.

**Tools & Technologies:** NI Multisim, Oscilloscope, Function Generator, DMM, Op-Amps, Analog Circuit Design

---

### Electronics Enclosure CAD Design
Created a 3D CAD enclosure for an electronic system, applying mechanical design considerations to package and organize electrical components.

**Tools & Technologies:** Autodesk Fusion, CAD, 3D Modelling
